AutomergeConflictValue in types.rs needs `from_value_and_id` helper that takes `&Value` and `&ObjId`. For get_all, Automerge returns `Vec<(Value, ObjId)>` where ObjId represents the operation ID (ExId). The `AutomergeScalarValue::new()` is crate-private (not pub) in types.rs so it can be accessed from within types.rs. Inventory.rs needs `builtins_vec!` registration for any new FFI Vec types.
