Document discovery notification chain: SyncServer fires DocumentAvailable event when first seeing a document ID. SyncServerHostedService subscribes and broadcasts via IHubContext<DocumentsHub, IDocumentsHubClient>. SignalRNetworkAdapter implements IDocumentsHubClient.OnDocumentAvailable. RepoService maintains _knownDocumentIds HashSet and fires DocumentsChanged. Demo apps subscribe via DocumentSessionDialogViewModel. Key pattern: use IHubContext injected via DI to broadcast from outside a hub (hubs are transient).
