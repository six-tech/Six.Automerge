AutomergeScalarValue can be passed from C# to Rust FFI as input — construct with typed helper methods (CreateStringScalar, CreateBoolScalar, CreateIntScalar) setting value_type and the corresponding field, with empty VecU8 for unused byte fields. The `to_scalar_value()` reverse conversion on Rust side converts back to `ScalarValue`. Automerge mark/unmark: `start > end` is silently accepted as no-op (no exception). The parameter name `value` is forbidden by Interoptopus — use `mark_value` or similar. ExpandMark default is `After`.
