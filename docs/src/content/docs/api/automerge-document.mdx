# Overview

`AutomergeDocument` is the primary class for working with Automerge CRDT documents. It provides methods for creating documents, reading and writing data, managing history, synchronizing with peers, and persisting state.

The class implements `IDisposable` because it holds a native Rust resource. Always use a `using` statement.

```csharp
using Six.Automerge;

using var doc = AutomergeDocument.Create();
```

# Creation and Disposal

## Create

```csharp
public static AutomergeDocument Create(string? actorId = null)
```

Creates a new empty Automerge document.

**Parameters:**
- `actorId` — Optional actor identifier. If null, a random actor ID is generated. If a valid hex string, it is used directly as the Automerge actor. If a non-hex string, it is UTF-8 encoded and used as the actor bytes.

**Returns:** A new `AutomergeDocument`.

**Exceptions:**
- `AutomergeException` — If the actor ID is invalid.

```csharp
using var doc = AutomergeDocument.Create();
using var docWithActor = AutomergeDocument.Create("my-app-device-1");
```

## Load

```csharp
public static AutomergeDocument Load(byte[] data)
```

Loads a document from binary data produced by `Save`.

**Parameters:**
- `data` — The binary document data. Must not be null or empty.

**Returns:** A new `AutomergeDocument` containing the loaded state.

**Exceptions:**
- `ArgumentNullException` — When `data` is null.
- `ArgumentException` — When `data` is empty.
- `AutomergeException` — When the data is invalid or corrupted.

```csharp
byte[] saved = originalDoc.Save();
using var restored = AutomergeDocument.Load(saved);
```

## LoadWithOptions

```csharp
public static AutomergeDocument LoadWithOptions(byte[] data, LoadOptions options)
```

Loads a document with configurable verification and error handling.

**Parameters:**
- `data` — The binary document data. Must not be null or empty.
- `options` — Load configuration. See `LoadOptions`.

**Returns:** A new `AutomergeDocument`.

**Exceptions:**
- `ArgumentNullException` — When `data` or `options` is null.
- `ArgumentException` — When `data` is empty.
- `AutomergeException` — When the data is invalid.

```csharp
var options = new LoadOptions
{
  VerificationMode = VerificationMode.NoCheck,
  OnPartialLoad = OnPartialLoad.Ignore
};
using var doc = AutomergeDocument.LoadWithOptions(saved, options);
```

## Dispose

```csharp

```

Releases the native Automerge document. Automatically rolls back any uncommitted changes before disposal to prevent native panics.

## RootId

```csharp
public AutomergeObjectId RootId { get; }
```

Gets the root object ID. Every document has a root Map container where top-level data is stored.

**Exceptions:**
- `ObjectDisposedException` — When the document has been disposed.

```csharp
var root = doc.RootId;

```

## ActorId

```csharp
public string ActorId { get; set; }
```

Gets or sets the actor identifier for this document. The actor ID identifies who made changes and is important for synchronization.

When getting: returns the human-readable string if the hex can be decoded to printable UTF-8, otherwise returns the raw hex.

When setting: hex strings are used directly; non-hex strings are UTF-8 encoded.

**Exceptions:**
- `ArgumentException` — When setting to null or whitespace.
- `AutomergeException` — When the value is invalid.

```csharp
doc.ActorId = "user-alice-device-1";
var actor = doc.ActorId;
```

## PendingOperations

```csharp
public ulong PendingOperations { get; }
```

Gets the number of uncommitted operations. Returns 0 after a `Commit` or `Rollback`.

# Commit and Rollback

## Commit

```csharp
public string? Commit(string? message = null, long? timestampMillis = null)
```

Commits all pending operations as a single change.

**Parameters:**
- `message` — Optional commit message describing the change.
- `timestampMillis` — Optional Unix timestamp in milliseconds. If null, Automerge uses its default.

**Returns:** The change hash as a lowercase hex string, or null if there were no pending operations.

```csharp
doc.PutString(root, "title", "Hello");
var hash = doc.Commit("Set title");
```

## Rollback

```csharp
public ulong Rollback()
```

Discards all uncommitted operations and returns the number of operations rolled back.

**Returns:** The number of operations that were rolled back.

```csharp
doc.PutString(root, "title", "mistake");
var count = doc.Rollback(); // count = 1, change discarded
```

## EmptyChange

```csharp
public string EmptyChange(string? message = null, long? timestampMillis = null)
```

Creates a commit with no operations. Useful for creating a merge point or recording metadata.

**Parameters:**
- `message` — Optional commit message.
- `timestampMillis` — Optional timestamp.

**Returns:** The change hash as a lowercase hex string.

# Text Operations

## SpliceText

```csharp
public void SpliceText(AutomergeObjectId textId, ulong index, long deleteCount, string text)
```

Inserts and/or deletes text at the given position. This is the primary text editing operation.

**Parameters:**
- `textId` — The target Text object.
- `index` — The character position (0-based).
- `deleteCount` — Number of characters to delete starting at `index`.
- `text` — Text to insert at `index` (after deletion). Use empty string to only delete.

```csharp
var textId = doc.PutObject(root, "content", AutomergeContainerType.Text);
doc.SpliceText(textId, 0, 0, "Hello world");    // Insert
doc.SpliceText(textId, 5, 6, "");               // Delete " world"
doc.SpliceText(textId, 5, 0, " everyone");      // Insert " everyone"
// Result: "Hello everyone"
```

Creates a cursor that tracks a logical position in a List or Text. The cursor follows the element at the given index even as concurrent edits shift indices.

# Rich Text — Spans

## GetSpans

```csharp
public IReadOnlyList<AutomergeSpan> GetSpans(AutomergeObjectId textId)
```

Gets the text as a sequence of spans. Each span is either an `AutomergeTextSpan` (text with marks) or an `AutomergeBlockSpan` (block-level marker).

**Returns:** An ordered list of spans representing the rich text structure.

```csharp
var spans = doc.GetSpans(textId);
foreach(var span in spans)
{
  if(span is AutomergeTextSpan textSpan)
    Console.WriteLine($"Text: \"{textSpan.Text}\" marks: {textSpan.Marks.Count}");
  else if(span is AutomergeBlockSpan blockSpan)
    Console.WriteLine($"Block: {blockSpan.BlockType}");
}
```

# Branching

## Fork

```csharp
public AutomergeDocument Fork()
```

Creates an independent copy of the document with a new actor ID. The forked document shares the same history but diverges from this point. Changes made to the fork can be merged back later.

**Returns:** A new `AutomergeDocument` that is a fork of the current state.

```csharp
using var fork = doc.Fork();
fork.PutString(fork.RootId, "key", "fork-value");
fork.Commit("Change on fork");
doc.Merge(fork); // Merge changes back
```

## ForkAtHeads

```csharp
public AutomergeDocument ForkAtHeads(IEnumerable<string> heads)
```

Creates a fork at a specific historical point. Useful for creating concurrent branches from a past state.

**Parameters:**
- `heads` — The heads to fork at. Must not be empty.

**Returns:** A new `AutomergeDocument` representing the state at those heads.

**Exceptions:**
- `ArgumentNullException` — When `heads` is null.
- `ArgumentException` — When `heads` is empty or contains invalid hashes.

## Clone

```csharp
public AutomergeDocument Clone()
```

Creates an exact copy of the document via Save/Load. Unlike `Fork`, the clone has the same actor ID (you should set a new one before making changes).

**Returns:** A new `AutomergeDocument` with the same state.

## ViewAtHeads

```csharp
public AutomergeDocument ViewAtHeads(IEnumerable<string> heads)
```

Creates a read-only view of the document at a specific historical point. Internally creates a clone and isolates it to the specified heads.

**Parameters:**
- `heads` — The heads representing the desired point in history.

**Returns:** A new `AutomergeDocument` showing the state at those heads.

## Merge

```csharp
public IReadOnlyList<string> Merge(AutomergeDocument other)
```

Merges all changes from another document into this one. After merging, this document contains changes from both documents.

**Parameters:**
- `other` — The document to merge from.

**Returns:** The new head hashes after merging.

**Exceptions:**
- `ArgumentNullException` — When `other` is null.

```csharp
var newHeads = doc.Merge(otherDoc);
```

## Isolate

```csharp
public void Isolate(IEnumerable<string> heads)
```

Hides changes after the specified heads, making the document appear as it was at that point. The hidden changes are not lost — call `Integrate` to restore them.

**Parameters:**
- `heads` — The heads to isolate to.

## Integrate

```csharp

```

Restores any changes previously hidden by `Isolate`, returning the document to its full state.

## SaveIncremental

```csharp

var baseHeads = doc.GetHeads();
```

# Synchronization

## CreateSyncState

```csharp
public AutomergeSyncState CreateSyncState()
```

Creates a new sync state for synchronizing with a peer. Convenience method equivalent to `AutomergeSyncState.Create()`.

**Returns:** A new `AutomergeSyncState`.

## GenerateSyncMessage

```csharp
public byte[]? GenerateSyncMessage(AutomergeSyncState state)
```

Generates the next sync message to send to a peer. Returns null when synchronization is complete (no more messages to send).

**Parameters:**
- `state` — The sync state for this peer connection.

**Returns:** Binary sync message to send, or null if synchronized.

## ReceiveSyncMessage

```csharp
public void ReceiveSyncMessage(AutomergeSyncState state, ReadOnlySpan<byte> message)
```

Processes a sync message received from a peer. Updates both the document and the sync state.

**Parameters:**
- `state` — The sync state for this peer connection.
- `message` — The binary sync message received from the peer.

**Example — Full sync loop between two documents:**

```csharp
using var syncAB = docA.CreateSyncState();
using var syncBA = docB.CreateSyncState();

for(int i = 0; i < 10; i++)
{
  var msgA = docA.GenerateSyncMessage(syncAB);
  var msgB = docB.GenerateSyncMessage(syncBA);

  if(msgA == null && msgB == null)
    break; // Synchronized

  if(msgA != null)
    docB.ReceiveSyncMessage(syncBA, msgA);
  if(msgB != null)
    docA.ReceiveSyncMessage(syncAB, msgB);
}
```

# Diff and Patches

## Diff

```csharp
public IReadOnlyList<AutomergePatch> Diff(
  IEnumerable<string> beforeHeads, IEnumerable<string> afterHeads)
```

Computes the differences between two points in the document history.

**Parameters:**
- `beforeHeads` — The starting state.
- `afterHeads` — The ending state.

**Returns:** A list of patches describing what changed. Each `AutomergePatch` contains an `ObjectId`, `Path` from root, and `Action` describing the change.

```csharp
var before = doc.GetHeads();

var after = doc.GetHeads();

var patches = doc.Diff(before, after);
foreach(var patch in patches)
{
  Console.WriteLine($"{patch.Action.Kind} on {patch.ObjectId}");
}
```
