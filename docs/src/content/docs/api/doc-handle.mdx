# Overview

`DocHandle<T>` is the primary way to interact with documents managed by a `Repo`. It wraps an `AutomergeDocument` with a lifecycle state machine, change events, thread-safe access, and sync coordination. Handles are obtained from `Repo.Create`, `Repo.Find`, `Repo.Clone`, or `Repo.Import`.

```csharp
using Six.Automerge.Repository;

var handle = repo.Create<object>();
handle.Change(doc =>
{
  doc.PutString(doc.RootId, "title", "Hello");
});
var document = handle.Doc();
```

**Namespace:** `Six.Automerge.Repository`

# HandleState

```csharp
public enum HandleState
```

The lifecycle state of a document handle.

| Value | Description |
|-------|-------------|
| `Idle` | Initial state before any loading begins |
| `Loading` | Document is being loaded from storage |
| `Requesting` | Document is being requested from the network |
| `Ready` | Document is loaded and ready for use |
| `Unloaded` | Document has been unloaded from memory |
| `Deleted` | Document has been deleted |
| `Unavailable` | Document could not be found from any source |

**State transitions:**

```
Idle → Loading → Ready
Idle → Loading → Requesting → Ready
Ready → Unloaded → Loading (reload)
Ready → Deleted
Requesting → Unavailable
```

# IDocHandle

```csharp
public interface IDocHandle : IDisposable
```

Non-generic interface for document handles. Allows storing handles with different type parameters in the same collection (e.g., the repo's handle cache).

## Properties

| Property | Type | Description |
|----------|------|-------------|
| `DocumentId` | `DocumentId` | The unique identifier for this document |
| `State` | `HandleState` | The current lifecycle state |
| `IsReady` | `bool` | True when `State` is `Ready` |
| `IsUnloaded` | `bool` | True when `State` is `Unloaded` |
| `IsDeleted` | `bool` | True when `State` is `Deleted` |
| `IsUnavailable` | `bool` | True when `State` is `Unavailable` |
| `IsReadOnly` | `bool` | True if the handle is a fixed-heads view |
| `Heads` | `IReadOnlyList of string` | Current document heads |

## Lifecycle Methods

| Method | Description |
|--------|-------------|
| `Begin()` | Transitions from `Idle` to `Loading` |
| `Initialize(document, isNewDocument)` | Initializes with a document, transitions to `Ready` |
| `DoneLoading()` | Transitions from `Loading`/`Requesting` to `Ready` |
| `Request()` | Transitions from `Loading` to `Requesting` |
| `MarkUnavailable()` | Transitions to `Unavailable` |
| `Unload()` | Transitions to `Unloaded`, releases document |
| `Reload()` | Transitions from `Unloaded` to `Loading` |
| `Delete()` | Transitions to `Deleted` |

# Mutation

## Change

```csharp
public DocLocalChange<T>? Change(
  Action<AutomergeDocument> mutation,
  string? message = null,
  long? timestampMillis = null,
  CancellationToken cancellationToken = default)
```

Makes a change to the document. Acquires a lock, applies the mutation, commits, and fires change events.

**Parameters:**
- `mutation` — An action that modifies the `AutomergeDocument`.
- `message` — Optional commit message.
- `timestampMillis` — Optional timestamp.

**Returns:** A `DocLocalChange<T>` with the change hash and binary data, or null if the mutation produced no operations.

```csharp
var change = handle.Change(doc =>
{
  doc.PutString(doc.RootId, "status", "active");
}, "update status");
```

## ChangeAsync

```csharp
public async ValueTask<DocLocalChange<T>?> ChangeAsync(

  CancellationToken cancellationToken = default)
```

Async version of `Change`.

## ChangeAt

```csharp
public IReadOnlyList<byte[]> ChangeAt(
  IReadOnlyList<string> heads,
  Action<AutomergeDocument> mutation)
```

Makes a change as if at the specified heads, creating a concurrent branch. Forks the document at the given heads, applies the mutation, commits, then merges back.

**Parameters:**
- `heads` — The heads to fork at.
- `mutation` — The mutation to apply.

**Returns:** Binary change data from the concurrent branch.

**Exceptions:**
- `ArgumentNullException` — When `heads` or `mutation` is null.
- `ArgumentException` — When `heads` is empty.
- `InvalidOperationException` — When the handle is not ready or is read-only.
