# Overview

The repository layer uses several identifier types for type safety and validation. All identifier types are `readonly record struct` values with implicit conversions to and from `string`.

| Type | Purpose | Example |
|------|---------|---------|
| `DocumentId` | Identifies a document (Base58Check-encoded) | `"4NMNnkMhL8jXrdJ9jamS58PAVdXu"` |
| `PeerId` | Identifies a peer in the network | `"peer-a1b2c3d4"` |
| `StorageId` | Identifies a storage location or peer for sync state | `"storage-main"` |
| `SessionId` | Identifies a session for ephemeral message deduplication | `"a1b2c3d4e5f6..."` |
| `StorageKey` | Hierarchical key for storage operations | `"doc123/snapshot/abc"` |
| `AutomergeUrl` | URL format for sharing document references | `"automerge:4NMNnk..."` |

# DocumentId

```csharp
public readonly record struct DocumentId
```

A Base58Check-encoded Automerge document identifier. The encoding includes a checksum for validation.

**Namespace:** `Six.Automerge.Repository`

```csharp

```

The encoded document identifier string.

## Constructor

```csharp

```

**Exceptions:**
- `ArgumentException` — When `value` is null or whitespace.

## Static Methods

### Generate

```csharp

```

Generates a new random document ID from a GUID.

```csharp

```

### FromBinary

```csharp

public static DocumentId FromBinary(ReadOnlySpan<byte> bytes)
```

Creates a document ID from binary data (at least 16 bytes). The data is Base58Check-encoded.

**Exceptions:**
- `ArgumentNullException` — When `bytes` is null.
- `ArgumentException` — When `bytes` is empty or under 16 bytes.

**Exceptions:**
- `ArgumentException` — When `value` is null or whitespace.
- `FormatException` — When `value` is not a valid Base58Check-encoded ID.

# AutomergeUrl

```csharp
public static class AutomergeUrl
```

Utilities for parsing and formatting Automerge URLs. Format: `automerge:{documentId}[#head1|head2|...]`

**Namespace:** `Six.Automerge.Repository`

## Methods

### Parse

```csharp
public static ParsedAutomergeUrl Parse(string url)
```

Parses an Automerge URL into a document ID and optional heads.

**Returns:** A `ParsedAutomergeUrl` record.

**Exceptions:**
- `ArgumentException` — When `url` is null or whitespace.
- `FormatException` — When the URL format is invalid or does not start with `"automerge:"`.

```csharp
var parsed = AutomergeUrl.Parse("automerge:4NMNnkMhL8jXrdJ9jamS58PAVdXu#head1|head2");
Console.WriteLine(parsed.DocumentId); // "4NMNnkMhL8jXrdJ9jamS58PAVdXu"
Console.WriteLine(parsed.Heads?.Count); // 2
```

### Format

```csharp
public static string Format(DocumentId documentId, IEnumerable<string>? heads = null)
public static string Format(string documentId, IEnumerable<string>? heads = null)
```

Formats a document ID and optional heads into an Automerge URL.

```csharp
var url = AutomergeUrl.Format(docId);
// "automerge:4NMNnkMhL8jXrdJ9jamS58PAVdXu"

var urlWithHeads = AutomergeUrl.Format(docId, new[] { "abc", "def" });
// "automerge:4NMNnkMhL8jXrdJ9jamS58PAVdXu#abc|def"
```

