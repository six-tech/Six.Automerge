# Overview

Network adapters transport Automerge sync messages between peers. The `INetworkAdapter` interface defines the contract for any transport (WebSocket, SignalR, WebRTC, in-memory, etc.). The repo uses adapters to discover peers, send/receive messages, and manage connections.

```csharp
using Six.Automerge.Repository.Network;

public class MyNetworkAdapter : INetworkAdapter
{
  public string AdapterId { get; } = Guid.NewGuid().ToString("N");
  public bool IsReady { get; private set; }
  // ... implement interface
}
```

**Namespace:** `Six.Automerge.Repository.Network`

# INetworkAdapter

```csharp
public interface INetworkAdapter
```

Interface for network adapters. Implementations must be thread-safe — methods may be called from any thread, and events may be raised from any thread.

## Properties

### AdapterId

```csharp
string AdapterId { get; }
```

Unique identifier for this adapter instance.

### IsReady

```csharp
bool IsReady { get; }
```

Whether the adapter is ready to send and receive messages.

## Methods

### WhenReady

```csharp
Task WhenReady()
```

Returns a task that completes when the adapter is ready. Use this to wait for connection establishment before sending messages.

### Connect

```csharp
void Connect(PeerId peerId, PeerMetadata? metadata = null)
```

Initiates a connection to a peer.

**Parameters:**
- `peerId` — The peer to connect to.
- `metadata` — Optional metadata about the connection.

### Send

```csharp
void Send(IRepoMessage message)
```

Sends a message through this adapter.

**Parameters:**
- `message` — The message to send. See [Message Types](#message-types) below.

### Disconnect

```csharp
Task Disconnect()
```

Disconnects the adapter and cleans up resources.

## Events

### PeerCandidate

```csharp
event EventHandler<PeerCandidateEventArgs>? PeerCandidate
```

Raised when a new peer is discovered or connected. The `PeerCandidateEventArgs` contains `PeerId` and optional `Metadata`.

### PeerDisconnected

```csharp
event EventHandler<PeerDisconnectedEventArgs>? PeerDisconnected
```

Raised when a peer disconnects. The `PeerDisconnectedEventArgs` contains `PeerId`.

### MessageReceived

```csharp
event EventHandler<MessageReceivedEventArgs>? MessageReceived
```

Raised when a message is received from a peer. The `MessageReceivedEventArgs` contains the `Message`.

### Closed

```csharp
event EventHandler? Closed
```

Raised when the adapter is closed.

# PeerMetadata

```csharp
public sealed record PeerMetadata
```

Metadata about a peer connection.

| Property | Type | Description |
|----------|------|-------------|
| `StorageId` | `StorageId?` | Storage identifier for this peer. If provided, sync state is persisted for faster reconnection |
| `IsEphemeral` | `bool` | If true, sync state is not persisted for this peer |
| `CustomData` | `IReadOnlyDictionary of string, object?` | Custom application metadata |

```csharp
var metadata = new PeerMetadata
{
  StorageId = new StorageId("storage-peer-1"),
  IsEphemeral = false,
  CustomData = new Dictionary<string, object>
  {
    ["role"] = "server",
    ["version"] = "2.0"
  }
};
```

# IRepoMessage

```csharp
public interface IRepoMessage
```

Base interface for all repo messages exchanged between peers.

| Property | Type | Description |
|----------|------|-------------|
| `MessageType` | `string` | The type discriminator (e.g., `"sync"`, `"request"`) |
| `DocumentId` | `DocumentId?` | The document this message relates to (null for some message types) |
| `SenderId` | `PeerId?` | The peer who sent this message (set by the network subsystem) |

# Message Types

## SyncMessage

```csharp
public sealed record SyncMessage : IRepoMessage
```

Automerge sync protocol message. Contains the binary sync data generated by `AutomergeDocument.GenerateSyncMessage`.

| Property | Type | Description |
|----------|------|-------------|
| `MessageType` | `string` | `"sync"` |
| `DocumentId` | `DocumentId` | The document being synchronized |
| `Data` | `byte[]` | Binary sync protocol data |
| `SenderId` | `PeerId?` | The sending peer |

## RequestMessage

```csharp
public sealed record RequestMessage : IRepoMessage
```

Request for a document. Sent when a peer wants to initiate sync for a document it does not have.

| Property | Type | Description |
|----------|------|-------------|
| `MessageType` | `string` | `"request"` |
| `DocumentId` | `DocumentId` | The requested document |
| `Data` | `byte[]` | Initial sync data |
| `SenderId` | `PeerId?` | The requesting peer |

## DocumentSnapshotMessage

```csharp
public sealed record DocumentSnapshotMessage : IRepoMessage
```

Contains a serialized Automerge document snapshot. Used for initial sync when a full document is sent rather than incremental sync messages.

| Property | Type | Description |
|----------|------|-------------|
| `MessageType` | `string` | `"doc-snapshot"` |
| `DocumentId` | `DocumentId` | The document |
| `Data` | `byte[]` | Full document binary data |
| `SenderId` | `PeerId?` | The sending peer |

## DocumentUnavailableMessage

```csharp
public sealed record DocumentUnavailableMessage : IRepoMessage
```

Indicates a document is not available from the sending peer.

| Property | Type | Description |
|----------|------|-------------|
| `MessageType` | `string` | `"doc-unavailable"` |
| `DocumentId` | `DocumentId` | The unavailable document |
| `SenderId` | `PeerId?` | The responding peer |

## EphemeralMessage

```csharp
public sealed record EphemeralMessage : IRepoMessage
```

Ephemeral (transient) message not persisted in document history. Used for presence indicators, cursor positions, and other temporary state.

| Property | Type | Description |
|----------|------|-------------|
| `MessageType` | `string` | `"ephemeral"` |
| `DocumentId` | `DocumentId` | The related document |
| `Data` | `byte[]` | Binary payload |
| `Count` | `int` | Sequence number for deduplication |
| `SessionId` | `SessionId` | Session ID for deduplication |
| `SenderId` | `PeerId?` | The sending peer |

## RemoteHeadsChangedMessage

```csharp
public sealed record RemoteHeadsChangedMessage : IRepoMessage
```

Notifies peers that remote heads have changed. Optional feature for optimistic UI updates.

| Property | Type | Description |
|----------|------|-------------|
| `MessageType` | `string` | `"remote-heads-changed"` |
| `DocumentId` | `DocumentId` | The document whose heads changed |
| `NewHeads` | `IReadOnlyList of string` | The new head hashes |
| `SenderId` | `PeerId?` | The sending peer |

## RemoteSubscriptionChangeMessage

```csharp
public sealed record RemoteSubscriptionChangeMessage : IRepoMessage
```

Controls remote heads subscriptions. Allows peers to subscribe/unsubscribe from head change notifications.

| Property | Type | Description |
|----------|------|-------------|
| `MessageType` | `string` | `"remote-subscription-change"` |
| `Add` | `IReadOnlyList of DocumentId?` | Document IDs to subscribe to |
| `Remove` | `IReadOnlyList of DocumentId?` | Document IDs to unsubscribe from |
| `SenderId` | `PeerId?` | The sending peer |

Note: `DocumentId` on the `IRepoMessage` interface returns `null` for this message type.
