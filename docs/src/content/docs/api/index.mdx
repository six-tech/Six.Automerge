# Overview

This section provides a complete reference for every public class and method in the Six.Automerge library. Each page documents method signatures, parameters, return types, exceptions, and usage examples.

# Core Classes

| Class | Description |
|-------|-------------|
| [AutomergeDocument](/Six.Automerge/api/automerge-document/) | The primary class for creating, reading, and writing Automerge CRDT documents. Contains 130+ methods organized by category. |
| [AutomergeSyncState](/Six.Automerge/api/automerge-sync-state/) | Manages synchronization state between two peers during the Automerge sync protocol. |
| [AutomergeCursor](/Six.Automerge/api/automerge-cursor/) | A stable position reference in a list or text that tracks a logical position across concurrent edits. |

# Supporting Types

These types are used as parameters or return values by the core classes.

## Value Types

| Type | Reference | Description |
|------|-----------|-------------|
| `AutomergeScalarValue` | [Marks and Scalar Values](/Six.Automerge/api/automerge-marks/) | Represents a scalar value (string, int, bool, double, bytes, counter, timestamp, null). |
| `AutomergeConflictValue` | [Conflict Values](/Six.Automerge/api/automerge-conflicts/) | A value returned by conflict-aware methods like `GetAll`. Contains either a scalar or an object reference, plus the operation ID. |
| `ImmutableString` | [Options and Utility Types](/Six.Automerge/api/automerge-options/) | A string wrapper signaling that the value should be replaced atomically, not merged character-by-character. Use for URLs, IDs, and enum-like constants. |

## Container and Object Types

| Type | Reference | Description |
|------|-----------|-------------|
| `AutomergeObjectId` | — | An opaque identifier for a container (Map, List, or Text) within a document. Obtained from `RootId` or methods that create containers. |
| `AutomergeContainerType` | [Options and Utility Types](/Six.Automerge/api/automerge-options/) | Enum with values `Map`, `List`, and `Text`. Specifies which container type to create. |

## Rich Text Types

| Type | Reference | Description |
|------|-----------|-------------|
| `AutomergeMarkInfo` | [Marks and Scalar Values](/Six.Automerge/api/automerge-marks/) | Describes a mark applied to a text range: `Name`, `Value`, `Start`, and `End`. |
| `AutomergeSpan` | [Spans](/Six.Automerge/api/automerge-spans/) | Base class for spans returned by `GetSpans`. Either an `AutomergeTextSpan` or an `AutomergeBlockSpan`. |
| `AutomergeTextSpan` | [Spans](/Six.Automerge/api/automerge-spans/) | A span of text with its active marks. Properties: `Text`, `Marks`. |
| `AutomergeBlockSpan` | [Spans](/Six.Automerge/api/automerge-spans/) | A block marker in rich text. Properties: `BlockType`, `Parents`, `AttributesJson`. |
| `ExpandMode` | [Marks and Scalar Values](/Six.Automerge/api/automerge-marks/) | Enum controlling how marks expand when text is inserted at their boundaries: `Before`, `After`, `Both`, `None`. |

## History and Diff Types

| Type | Reference | Description |
|------|-----------|-------------|
| `DecodedChange` | [Options and Utility Types](/Six.Automerge/api/automerge-options/) | Metadata about a committed change: `Hash`, `Actor`, `Sequence`, `TimestampMillis`, `Message`, `Dependencies`. |

| `AutomergePatchAction` | [Patches](/Six.Automerge/api/automerge-patches/) | Details of what changed: `Kind` (PutMap, PutSeq, Insert, SpliceText, Increment, Conflict, DeleteMap, DeleteSeq, Mark), plus kind-specific fields. |
| `AutomergePatchPathElement` | [Patches](/Six.Automerge/api/automerge-patches/) | One step in the path from the root to a changed object. Contains the `ObjectId` and `Prop` (key or index). |

# How to Read the Reference

Each method entry follows this format:

**Signature** shows the C# method signature with full parameter types and return type.

**Parameters** lists each parameter with its type and description. Optional parameters show their default values.

**Returns** describes the return value and when it may be null.

**Exceptions** lists exceptions that can be thrown and under what conditions.

**Example** provides a minimal working code snippet demonstrating typical usage.

# Namespace

All types are in the `Six.Automerge` namespace:

```csharp
using Six.Automerge;
```

# Disposal Pattern

`AutomergeDocument` and `AutomergeSyncState` implement `IDisposable` because they hold native (Rust) resources. Always use `using` statements:

```csharp
using var doc = AutomergeDocument.Create();
using var syncState = AutomergeSyncState.Create();
```

Failing to dispose these objects will leak native memory.

# Thread Safety

`AutomergeDocument` is **not thread-safe**. Do not call methods on the same document from multiple threads concurrently. If you need concurrent access, use the Repository layer (`Six.Automerge.Repo`) which serializes access through `DocHandle`.
